The measurement boundary travels with the number.

These are bounded implementation experiments on dated shared Linode nodes, with controlled CPU affinity and per-series worker limits. Fresh application state is not a machine-cold boot. Correctness is checked for every sample. Toolchains, commands, machine inventory and raw evidence accompany each report.

Minimal generated-page throughput and microbenchmarks do not replace real-site migration experiments. Read the workloads and limitations before quoting a result.
