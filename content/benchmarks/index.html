The measurement boundary travels with the number.

These are bounded implementation experiments on dated shared Linode nodes, with controlled CPU affinity and per-series worker limits. Fresh application state is not a machine-cold boot. Correctness is checked for every sample. Toolchains, commands, machine inventory and raw evidence accompany each report.

Minimal generated-page throughput and microbenchmarks do not replace real-site migration experiments. Read the workloads and limitations before quoting a result.

Current measured series: v4.12.0 candidate

All eight official suites use the unreleased Nift v4.12.0 candidate, exact source c14d06835bca515a5281e41da0e40219c2d60ef0. All 67,153 official observations and required recovery diagnostics passed independent audits. Historical measurements and diagnostics remain in lab-evidence, outside this current-results site.

Current strengths include metadata traversal, programmable template work and task running: Nift has the lowest wall-time and maximum-child RSS medians in all 31 official task configurations. Each report plots the final candidate against its current measured peers.

Remaining gaps stay visible: lightweight concurrency, interpreter/collection throughput, portable hashing, hot template reuse and native no-op overhead. AI-DX is a separate qualitative dimension alongside correctness and performance.

The website article separates official CPU0 results from the audited normal all-core supplement, and normal incremental nift build from forced full builds. No unmatched incremental peer ranking is implied.
