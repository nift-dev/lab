These are bounded implementation experiments on dated shared Linode nodes, with controlled CPU affinity and per-series worker limits. Fresh application state is not a machine-cold boot. Minimal generated-page throughput and microbenchmarks do not replace real-site migration experiments. Read the workloads and limitations before quoting a result.
